Integraciones

Stack Tecnológico

Backend

  • Python 3.11+ / FastAPI
  • Socket.io (WebSockets)
  • PostgreSQL (Supabase)
  • Google Gemini API
  • dnd5eapi.co

Frontend

  • React 18 + Vite
  • Tailwind CSS (mobile-first)
  • Zustand (estado global)
  • Socket.io-client
  • PWA (vite-plugin-pwa)
  • ammo.wasm (3D)

Alcance de Pruebas

✓ En Alcance

  • Autenticación y autorización
  • Gestión de campañas y roles
  • Hoja de personaje D&D 5e
  • Generación de NPCs con IA
  • OCR de hojas físicas
  • Asistente conversacional
  • Sincronización en tiempo real
  • PWA y modo offline
  • Visor 3D de dados

✗ Fuera de Alcance

  • Pruebas de carga masiva (+100 usuarios)
  • Penetration testing avanzado
  • Compatibilidad IE11
  • Dispositivos con OS >2 años
